# Buchi.io - Personal Portfolio Website

A modern, responsive portfolio website showcasing cloud engineering skills and projects. This static website is designed to be deployed to Azure Static Web Apps using Terraform for Infrastructure-as-Code.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Interactive Animations**: Particle effects, typing animation, smooth scrolling, and scroll-triggered animations
- **Modern UI**: Clean, professional design with gradient accents and hover effects
- **Contact Form**: Integrated contact form with email functionality

## Technologies Used

- HTML5
- CSS3 (with CSS variables and modern animations)
- Vanilla JavaScript (no frameworks required)
- Google Fonts (Inter)

## Sections

- **Hero**: Eye-catching introduction with particle animation and typing effect
- **About**: Overview of skills and expertise in cloud engineering
- **Projects**: Showcase of key projects including Azure IaC Migration, Mobile Game Development, and Static Web Deployment
- **Contact**: Multiple contact options including email, LinkedIn, and GitHub

## Skills Highlighted

- ☁️ Azure
- 🌐 AWS
- ⚓ Kubernetes
- 🏗️ Terraform
- 🔄 CI/CD
- 🐳 Docker

## Deployment

This project is designed to be deployed to Azure Static Web Apps using Terraform. The infrastructure is managed as code for reproducibility and version control.

## Local Development

To run this project locally, simply open `index.html` in a web browser. No build steps or dependencies are required.

```bash
# Clone the repository
git clone https://github.com/iBrid/my_webpage.git

# Open in browser
open index.html
```
